# 안심 체크 — Windows 10/11 보안 자가 점검 안내

## 실행 방법
`index.html`을 최신 웹 브라우저에서 열면 사용할 수 있습니다. 별도의 서버, 계정, 패키지 설치, 외부 글꼴 다운로드는 필요하지 않습니다.

## 기능
- Windows 10/11의 업데이트, 화면 잠금과 계정 보호, Windows 보안, 백업, 다운로드/링크 습관을 안내합니다.
- 사용자가 각 항목을 직접 확인해 **양호 응답 / 주의 필요 / 확인하지 못함** 중 하나를 선택합니다.
- 점검 화면에서 응답한 항목 수와 진행 막대를 갱신합니다. 고른 응답 수를 나타낼 뿐, 보안 상태를 평가하는 점수는 아닙니다.
- 결과 요약과 항목별 상태, 사용자가 실제로 고른 응답, 다음 조치를 보여 줍니다. 주의 및 미확인 항목을 먼저 표시합니다.
- **확인하지 못함**을 선택한 항목에는 Windows 지원 상태, 계정 보호, Windows 보안, 백업, 링크/다운로드 등 해당 주제에 맞는 별도의 확인 경로나 안전한 다음 단계를 제시합니다. 미확인은 양호로 계산하지 않으며 앱이 자동으로 기기를 진단하지 않습니다.
- 결과 화면에서 **응답 수정**을 선택하면 기존 응답을 유지한 채 점검으로 돌아갑니다. 점검 화면의 **처음으로** 또는 결과 화면의 **처음부터 다시 점검**을 누르면 응답과 진행 상태를 초기화합니다.
- 결과 화면의 접을 수 있는 **보안 사고가 의심될 때의 대처 방법** 안내는 의심스러운 링크·파일과의 상호작용을 멈추기, 공식 경로에서 계정 보호 조치하기, Windows 보안 검사를 고려하기, 회사·학교 기기나 랜섬웨어 의심 시 담당자에게 먼저 연락하기 등의 일반적인 다음 단계를 제공합니다. 이 앱이 사고를 감지하거나 조사·복구하는 것은 아닙니다.
- 결과 화면의 **결과 인쇄 또는 PDF 저장** 버튼은 브라우저의 인쇄 창을 엽니다. 인쇄 미리보기에서 프린터를 선택하거나 “PDF로 저장”을 선택할 수 있습니다. PDF에는 결과와 자가 점검의 한계/다음 조치 안내가 포함됩니다. 사고 안내는 화면에서 펼친 경우 인쇄될 수 있습니다. 이 앱은 문서를 서버로 보내거나 별도의 PDF 파일을 자동 저장하지 않습니다.
- 키보드 사용자를 위한 본문 바로가기 링크를 제공하고, 키보드 초점을 눈에 띄게 표시합니다. 각 선택 그룹은 확인 방법 설명과 연결되며, 선택 변경 시 선택 내용과 전체 응답 수를 보조기술에 알립니다.

## Windows 10/11의 주요 확인 경로
Windows 표시 언어, 에디션, 업데이트 상태에 따라 메뉴 이름이 조금 다를 수 있습니다.

- **업데이트:** Windows 11은 `설정 > Windows 업데이트`, Windows 10은 `설정 > 업데이트 및 보안 > Windows 업데이트`에서 확인합니다.
- **Windows 버전/에디션:** `설정 > 시스템 > 정보`의 Windows 사양을 확인합니다.
- **화면 잠금:** `설정 > 계정 > 로그인 옵션`에서 로그인 방법을 확인합니다.
- **보안 기능:** 시작 메뉴에서 `Windows 보안`을 검색해 열고 `바이러스 및 위협 방지`와 `방화벽 및 네트워크 보호`를 확인합니다. 앱 접근 경로는 Windows 11의 `설정 > 개인정보 및 보안 > Windows 보안`, Windows 10의 `설정 > 업데이트 및 보안 > Windows 보안`입니다.
- **백업:** 시작 메뉴에서 `백업 설정`을 검색하고, 사용 중인 백업 옵션과 최근 백업·복구 가능성을 확인합니다. 계정, 에디션 및 백업 방식에 따라 사용할 수 있는 기능이 다릅니다.

### Windows 10 지원 상태
Windows 10 Home/Pro 일반 지원은 **2025년 10월 14일 종료**되었습니다. 따라서 Windows 업데이트 화면에 최신 상태라고 표시되어도 일반 보안 지원 중이라는 뜻이 아닐 수 있습니다. 대상 기기에 등록된 ESU(확장 보안 업데이트)는 한시적으로 보안 업데이트를 제공할 수 있고, 일부 LTSC 에디션은 별도 수명주기를 따릅니다. 본인의 에디션, ESU 등록 및 지원 자격은 Microsoft의 공식 Windows 10 지원 안내에서 확인하세요. 앱은 이를 자동으로 검사하지 않습니다.

## 키보드와 접근성
- 키보드로 페이지에 진입한 뒤 Tab을 누르면 **본문 바로가기** 링크가 먼저 나타납니다. Enter를 누르면 본문으로 이동합니다.
- 각 응답 선택지는 개별 버튼입니다. **Tab 키로 각 선택지까지 차례로 이동**하고 Enter 또는 Space로 선택할 수 있습니다. 한 항목에서 새 응답을 선택하면 이전 응답은 해제됩니다.
- 각 항목의 선택 그룹은 해당 항목의 “확인 방법” 설명과 연결되어 있습니다. 화면 읽기 프로그램으로 그룹에 진입할 때 맥락을 함께 파악하는 데 도움이 됩니다.
- 보안 사고 안내는 기본 `<details>/<summary>` 방식으로 키보드에서 펼치거나 접을 수 있습니다. 응답을 선택하면 진행 상태의 라이브 안내가 해당 항목의 이름, 선택한 응답 및 전체 응답 수를 전달합니다. 화면 전환 시 주요 제목으로 초점을 이동하며, 운영체제의 동작 줄이기 설정이 켜져 있으면 화면 전환 시 부드러운 스크롤을 사용합니다.
- Windows 내레이터 시험은 **Windows 키 + Ctrl + Enter**로 시작할 수 있습니다. `USER_TESTING.md`의 시나리오 5에 응답 맥락, 선택 안내, 진행 수, 결과 읽기 순서를 확인하는 절차가 있습니다. 사용자는 내레이터 시험이 잘 작동했다고 보고했으며, 별도 환경·세부 관찰 기록은 없습니다.
- 실제 보조기술 및 브라우저 조합에서의 동작과 WCAG 적합성은 별도의 사용자·접근성 시험이 필요합니다. 이번 변경만으로 완전한 접근성 적합성을 보장하지 않습니다.

## 개인정보와 범위
선택 내용은 현재 페이지에서만 처리되고 저장되거나 서버로 전송되지 않습니다. 기존 웹 앱은 운영체제 설정을 읽지 않으며, 악성코드 검사·실제 공격 방어·설정 변경을 수행하지 않습니다. 결과는 사용자의 응답을 정리한 참고용 자가 점검이며 기기의 안전을 보장하지 않습니다. 미확인 항목은 양호로 간주하지 않습니다. 보안 사고 대처 안내는 일반 정보로서 감염·침해 확인, 사고 조사, 데이터 복구나 전문적인 대응을 대신하지 않습니다. 인쇄/PDF 출력은 브라우저 기능을 사용자가 직접 호출하는 것이며 앱 자체가 파일을 저장하지 않습니다.
