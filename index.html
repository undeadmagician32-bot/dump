1단계 · 직접 확인

해당하는 항목을 선택하세요

각 항목의 확인 방법을 참고해 현재 상태를 선택하세요. 잘 모르겠다면 확인하지 못함을 선택해도 괜찮습니다.

!

Windows 10을 사용한다면 지원 상태를 먼저 확인하세요.
Windows 10 Home/Pro의 일반 지원은 2025년 10월 14일 종료되었습니다. ESU(확장 보안 업데이트) 등록 기기에는 한시 보안 업데이트가 제공될 수 있으며, 일부 LTSC 에디션은 별도 수명주기를 따릅니다. Windows 업데이트 화면에 “최신 상태”라고 표시되는 것만으로 지원 중이라고 판단할 수 없습니다. 에디션과 버전은 설정 > 시스템 > 정보에서 확인하고, 자세한 자격과 상태는 Microsoft의 공식 Windows 10 지원 안내를 확인하세요.

응답한 항목 0 / 5 선택하지 않은 항목은 결과에서 ‘확인하지 못함’으로 표시됩니다.

전체 5개 항목 중 0개에 응답했습니다.

선택한 결과는 이 페이지 안에서만 사용되며 서버로 전송되거나 저장되지 않습니다.

2단계 · 결과와 다음 조치

점검 결과

아래 결과는 직접 선택한 응답을 정리한 것입니다. 앱이 기기의 실제 설정을 확인한 것은 아닙니다.

보안 사고가 의심될 때의 대처 방법 보기

이 점검표는 감염이나 계정 침해를 감지하지 않습니다. 의심스러운 일이 있었다면 아래의 일반적인 안전 조치를 참고하세요.

  1. 링크나 파일과의 상호작용을 멈추세요. 의심되는 파일을 다시 실행하거나 메시지에 답하지 말고, 공식 앱이나 웹사이트를 직접 열어 사실 여부를 확인하세요.
  2. 비밀번호나 결제 정보를 입력했다면 계정을 보호하세요. 신뢰할 수 있는 다른 기기에서 해당 서비스의 공식 앱이나 주소를 직접 열어 비밀번호를 바꾸고, 다른 로그인 세션을 종료하고, 다중 인증을 켜세요. 결제 정보가 노출됐다면 카드사나 금융기관의 공식 연락처로 문의하세요.
  3. 의심스러운 프로그램을 실행했거나 PC에 이상이 있다면 검사를 고려하세요. Windows 보안에서 바이러스 및 위협 방지의 검사 옵션을 열어 전체 검사를 실행할 수 있습니다. 경고가 계속되거나 조치가 어렵다면 신뢰할 수 있는 전문가의 도움을 받으세요.
  4. 파일이 갑자기 암호화되거나 회사·학교 기기라면 먼저 지원 담당자에게 연락하세요. 랜섬웨어가 의심되면 안전하게 할 수 있는 경우 네트워크 연결을 끊고, 백업 드라이브를 연결하거나 파일을 삭제하는 등 추가 변경을 하기 전에 조직의 IT 담당자 또는 신뢰할 수 있는 전문가의 안내를 받으세요.

상황마다 적절한 대응은 다를 수 있습니다. 이 안내는 사고 조사나 전문적인 복구를 대신하지 않습니다.
