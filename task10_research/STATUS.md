## 최종 제출까지 필요한 작업

1. 개인 관심 분야와 작성자 성명을 확인해 논문에 반영한다.
2. 참고문헌 URL을 새 시크릿 창에서 직접 열고 제목·저자/기관·연도·내용을 원문 대조한다.
3. 실험 또는 데이터로 검증된 실재 선행 연구를 하나 이상 찾아 초록/방법/결과를 확인하고, 연결 문장을 본문과 참고문헌에 추가한다.
4. Python 3 환경에서 `python analyze.py`를 실행하고 검증 결과를 확인한다.
5. 이 폴더를 로컬에서 ZIP 하나로 압축하고, 별도 위치에 풀어 파일 누락 여부를 확인한다.
6. 확인을 마친 뒤 이 상태표와 논문에서 미완성 안내를 업데이트한다. 이 작업이 완료되기 전에는 모든 기준 통과를 주장하지 않는다.
