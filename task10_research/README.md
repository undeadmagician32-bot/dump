# 과제 10 재현 패키지 파일 안내

## 포함 파일

- `paper.md` — 논문 본문(표지, 초록, 서론, 방법, 결과, 논의, 참고문헌, 재현 방법, AI 판단 구분)
- `raw_data.csv` — 직접 구성한 통제 문자열 12건과 관측값
- `analyze.py` — Python 3 표준 라이브러리 기반 재계산·일관성 확인 스크립트
- `AI_and_my_judgment.txt` — 제출용 AI와 나의 판단 3줄

## 재현 방법

Python 3 설치 환경에서 이 폴더를 작업 디렉터리로 열고 `python analyze.py`를 실행한다. 별도 패키지 설치, 계정, 인증, 인터넷 연결은 필요하지 않다. 이 작업 환경에서는 스크립트를 실행할 수 없어 실행 결과를 검증 완료라고 주장하지 않는다.

## 제출 전 남은 확인 사항

- 이 프로젝트 도구는 UTF-8 텍스트 파일 생성만 제공하고 ZIP/바이너리 생성 기능이나 명령 실행 기능이 없으므로 실제 ZIP 아카이브를 만들거나 압축 해제 검사를 수행하지 못했다. 폴더의 네 파일을 로컬 환경에서 ZIP 하나로 묶어야 한다.
- 참고문헌 URL을 브라우저로 실시간 열어 접근성, 제목 및 내용 일치를 검증하지 못했다. 제출 전 새 시크릿 창에서 URL을 확인해야 한다.
- 사용자 성명과 개인적 관심 분야를 제공받지 못했다. 논문은 작업상 주제를 계산언어학·텍스트 표현으로 명시하고, 이를 사용자 본인의 확정된 관심사라고 꾸미지 않았다. 제출 시 본인 정보로 표지를 갱신할 것.
- 실험/데이터로 검증된 선행 연구 논문을 확인하지 못했다. 따라서 T10-C16은 충족했다고 주장하지 않으며, 실재 여부와 초록/내용을 직접 확인한 연구를 찾아 연결할 필요가 있다.

이 안내에 적힌 로컬 확인이 완료되기 전에는 모든 통과 기준을 충족한 최종 ZIP 제출본이라고 볼 수 없다.
